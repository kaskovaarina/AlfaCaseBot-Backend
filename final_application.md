
## Функциональные требования
1. **Регистрация и авторизация** с безопасным хранением данных (хеширование паролей через bcrypt) и поддержкой сессий через JWT-токены с автоматическим обновлением.
2. **Просмотр каталога бизнес-кейсов** с детальным описанием условий.
3. **Ввод и отправка текстового решения** выбранного кейса через интерфейс приложения.
4. **Автоматизированная многоуровневая проверка решения**, включающая:
   - Проверку формальных критерий (объем 50–2000 слов, отсутствие >45% повторяющихся слов, запрет на повторение одной буквы >5 раз, только кириллица/латиница).
   - Проверку осмысленности и релевантности с помощью модели LinearSVM.
   - Сравнение с эталонным ответом для предотвращения прямой подмены текста.
   - Оценку по 5 критериям с помощью пяти Ridge-моделей (аудитория, решение, фин. модель, риски, доказательства).
5. **Итоговая оценка от 1 до 5**, рассчитываемая как среднее значение по пяти критериям.
6. **Генерация текстовой обратной связи** нейросетью GigaChat на основе числовых оценок.
7. **Предоставление доступа к эталонному решению** после первой попытки с последующей блокировкой повторной отправки этого кейса.
8. **Начисление очков** с учетом коэффициента попытки: 1-я попытка (1.0), 2-я (0.8), 3-я (0.6). После 3-й попытки очки не начисляются.
9. **Формирование рейтинга** топ-5 пользователей приложения.
10. **Просмотр личной статистики** в профиле (количество решенных кейсов, средний балл, уровень пользователя).
11. **Интерактивный гайд**, описывающий основные действия, правила начисления очков и критерии оценки.
12. **Персональный совет дня** на главном экране с бизнес-рекомендацией.
13. **Возможность оценки кейса** пользователем по шкале от 1 до 5 звёзд.
14. **Безопасный выход из аккаунта** с очисткой сохраненных токенов.

## Используемый стек технологий
- **Backend:** Python, FastAPI, SQLite, Scikit-learn (LinearSVM, Ridge), GigaChat API, bcrypt, JWT, Docker, Docker Compose.
- **Frontend:** Kotlin, Jetpack Compose, Retrofit, OkHttp, Coroutines, MVVM.
- **Инфраструктура:** VPS (Ubuntu), GitHub, GitHub Actions.
