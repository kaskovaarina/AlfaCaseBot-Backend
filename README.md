#  AlfaCaseBot: ИИ-тренажер с бизнес-кейсами

Мобильное приложение на Android для самостоятельной тренировки навыков решения бизнес-кейсов с использованием искусственного интеллекта. Приложение позволяет пользователям отправлять текстовые решения и получать оценку от 1 до 5, а также развернутую обратную связь от GigaChat.

## Стек технологий

**Backend:**
- Python, FastAPI
- Scikit-learn (LinearSVM, Ridge) 
- GigaChat API 
- SQLite, Docker, Docker Compose

**Frontend (Android):**
- Kotlin, Jetpack Compose
- Retrofit, OkHttp, Coroutines
- Архитектура MVVM
